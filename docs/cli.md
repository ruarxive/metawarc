# CLI reference

The command tree is generated by Click and verified by the test suite. Use
`metawarc COMMAND --help` for the complete options of the installed version.

| Command | Purpose |
| --- | --- |
| `index` | Build or refresh record/header sidecars with explicit modes and resume support. |
| `ingest` | Preview or apply incremental source classification and processing. |
| `index-content` | Extract links, PDF, OOXML, image, OLE, video, audio, or font metadata. |
| `catalog` | List stable archive IDs, sources, status, counts, and catalog revision. |
| `stats` | Aggregate indexed records by MIME type or extension. |
| `list-files` | Query records through typed filters and deterministic pagination. |
| `dump` | Stream selected payloads to safe names with limits and a checksum manifest. |
| `get` | Export one payload by record ID and optional archive ID. |
| `export-cdxj` | Export CDXJ (and optional path index) for external replay engines such as pywb. |
| `dump-metadata` | Export a derived metadata sidecar as JSON Lines. |
| `doctor` | Check schema, source fingerprints, sidecars, and workspace orphans. |
| `rebind` | Explicitly associate a stable archive ID with a verified moved source. |
| `cleanup` | Preview or apply retention-aware cleanup of retired/staging files. |
| `analyze` | Run summary, stored-metadata, hash, duplicate, link, or layered integrity reports. |
| `serve` | Start the bounded read-only REST API, including `/replay/...` website replay. |
| `replay` | Alias for `serve`; opens the same API with website replay routes. |
| `mcp` | Start the allowlisted read-only MCP tool server. |

Shared workspace commands accept `--dbfile` and `--data-dir`. Query values use
bound parameters. Only local `list-files` and `dump` accept the visibly unsafe
`--unsafe-where` escape hatch. Mutating recovery operations preview by default
and require `--apply` where removal is involved.

## Website replay

`metawarc serve` and `metawarc replay` (alias) expose:

| Path | Behavior |
| --- | --- |
| `/` or `/replay` | HTML home listing archived hosts with replay links |
| `/replay/sites` | JSON list of hosts, entry URLs, and replay paths |
| `/replay/<YYYYMMDDHHMMSS>/<url>` | Closest exact-URL capture; HTML/CSS rewritten |
| `/replay/<YYYYMMDDHHMMSS>mp_/<url>` | Explicit rewritten mode |
| `/replay/<YYYYMMDDHHMMSS>id_/<url>` | Raw identity mode (no rewrite/banner) |

Redirects rewrite `Location` into the replay URL space. Scripts are not
rewritten. For full JS fidelity, export CDXJ and use external pywb:

```bash
metawarc export-cdxj --dbfile collection.db -o collection.cdxj --path-index paths.tsv
```

## Progress reporting

Long-running `index`, applied `ingest`, `index-content`, `dump`,
`dump-metadata`, `analyze hashes`, and deep `analyze integrity` operations show
progress automatically when stderr is an interactive terminal. Progress is
written to stderr, while results and machine-readable data remain on stdout.

Each covered command accepts `--progress` to force display and `--no-progress`
to disable it. `--silent`, dry-run ingestion, JSON output modes, JSON Lines
metadata written to stdout, and non-interactive auto mode suppress progress.
Unknown totals are shown as open-ended counters without a percentage or ETA;
Metawarc does not pre-scan a WARC merely to calculate a progress total.

## Stored metadata analysis

`analyze metadata` summarizes already indexed metadata envelopes without opening
source WARC payloads. Repeat `--type` to select `pdfs`, `images`, `ooxmldocs`,
`oledocs`, `videos`, `audio`, or `fonts`. Omitting the option or passing
`--type all` analyzes all seven types;
`all` cannot be combined with an explicit type. Link sidecars remain available
through `analyze links`.

```bash
metawarc analyze metadata --dbfile collection.db --type all
metawarc analyze metadata --dbfile collection.db --type pdfs --type images --top 20
```

Each type reports extraction successes and errors, warning rows and occurrences,
raw and normalized metadata coverage, inspected bytes, duration, normalized
field coverage, and top title, creator, created, modified, and application
values. Archive filtering and table, JSON, CSV, and Parquet output use the common
analysis options.

The media groups cover common web formats: video includes MP4/QuickTime, AVI,
WebM/Matroska, Ogg, MPEG, transport streams, ASF/WMV, FLV, and RealMedia; audio
includes MP3, WAV, AIFF, AU, FLAC, Ogg/Opus, M4A, WMA, MIDI, and RealAudio; fonts
include TTF/OTF, collections, WOFF/WOFF2, and EOT. Image extraction includes GIF,
SVG, WebP, BMP, ICO, PSD, XCF, PCX, TGA, CR2, WMF, and EMF in addition to the
previous JPEG, PNG, TIFF, and JPEG 2000 families.
